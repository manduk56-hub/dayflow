# Dayflow 0.1.2

Windows용 하루 일정 생성 프로그램입니다. AI API와 계정 없이 작동합니다.

## 실행

배포 폴더의 `Dayflow.exe`를 실행하세요. 실행 파일 옆의 모든 파일이 필요하므로 폴더 전체를 보관하세요. 서명하지 않은 초기 개발 빌드입니다.

소스에서 실행하려면 Node.js 설치 후 이 폴더에서 `npm install`, `npm start`를 실행하세요. `npm test`로 계산 로직을 검증하고 `npm run package`로 Windows x64 실행 폴더를 생성합니다.

## 사용법

1. 시작·종료 시간과 집중·휴식 길이를 선택합니다.
2. 할 일을 추가하고 비중을 0~10으로 설정합니다. 0이면 배정에서 제외됩니다. 각 항목 왼쪽 점 손잡이를 누른 채 드래그하면 항목이 마우스를 따라 움직입니다. 다른 항목의 중간을 넘으면 주변 항목이 부드럽게 이동해 자리를 바꾸고, 놓으면 순서가 자동 저장됩니다. 목록 밖에서 놓거나 Escape를 누르면 취소합니다. 손잡이에 키보드 포커스를 둔 뒤 위·아래 방향키로도 이동할 수 있습니다.
3. ‘일정 만들기’를 누릅니다. 비중에 따라 집중 시간을 분 단위로 배분합니다.
4. 각 작업 구간의 칸 전체(이름·시간·빈 공간)를 눌러 완료 체크를 켜거나 끌 수 있습니다. 일정표 아래 ‘이미지 복사’를 누르면 오른쪽 일정표 전체(날짜, 시간 합계, 배분 바, 완료 체크와 모든 구간)를 이미지로 클립보드에 복사하며 Ctrl+V로 붙여넣을 수 있습니다. 화면 아래로 이어지는 구간도 빠짐없이 포함합니다. 원형 보기에서는 원형 일과표와 전체 구간 목록을 함께 담습니다. 체크박스는 키보드로도 조작할 수 있으며 PDF 또는 CSV로 저장할 수 있습니다. PDF는 이미지 복사와 같은 전체 일정표 이미지 한 장을 한 페이지에 담습니다. 페이지 높이는 일정 길이에 맞춰 늘어나며 긴 일정도 중간에서 나뉘지 않습니다. 원형 보기에서는 원형 일과표와 전체 구간 목록을 함께 포함합니다. 이미지 기반 PDF이므로 글자 선택·검색은 지원하지 않습니다.

할 일 박스의 ‘비중 배정 단위’에서 1분·5분·10분을 선택합니다. 비중 작업의 총 배정 시간을 선택한 단위로 나누며, 단위로 나누고 남는 분은 마지막 비중 작업에 더해 전체 시간을 보존합니다. 직접 시간과 고정 시간은 입력한 분량을 유지합니다. 휴식 때문에 나뉜 개별 구간은 선택한 단위보다 짧거나 단위의 배수가 아닐 수 있습니다. 단위 변경은 일정에 즉시 반영되며 로컬에 저장됩니다.

각 할 일 오른쪽에서 ‘비중’ 또는 ‘직접 시간’을 선택할 수 있습니다. 직접 시간은 1~1439분으로 지정하며 할 일 박스에 유지됩니다. 직접 지정한 작업과 고정 활동의 시간을 먼저 확보하고 남은 시간에서 비중 작업과 휴식을 계산합니다. 직접 시간 작업은 목록 순서대로 진행하며 집중·휴식 주기에 맞춰 여러 구간으로 나뉠 수 있습니다. 입력한 시간은 휴식을 제외한 총 작업 시간으로 유지됩니다. 직접 작업과 휴식을 모두 넣을 수 없으면 작업 시간을 줄이거나 전체 시간을 늘리도록 안내합니다. 직접 시간 작업은 집중 합계에 포함되고, 식사·약속 등 고정 활동은 고정 시간 합계에 포함됩니다. 방식이나 시간을 바꾸면 만든 일정에 즉시 반영됩니다.

휴식은 전체 시간에 포함됩니다. 마지막에도 휴식 구간이 들어갈 수 있고 남은 시간이 짧으면 구간이 줄어듭니다. 종료가 시작보다 이르면 다음 날 종료로 처리합니다. 시작과 종료가 같으면 입력 오류입니다. 비중은 완료까지 걸리는 시간이 아닌 원하는 시간 투자 비율입니다. 목록 순서로 작업을 진행합니다.

작업이 지나치게 나뉘지 않도록 가까운 작업 경계에 휴식을 맞춥니다. 집중 기준의 ±20% 범위에서 휴식 시점을 조정하지만, 작업별 배정 분량과 전체 집중·휴식 시간은 그대로 유지합니다. 예를 들어 4시간, 집중 기준 50분, 휴식 10분, 비중 5:3:2라면 작업별 100분·60분·40분을 배정하고 두 번째 작업은 60분 한 구간으로 진행합니다. 긴 작업은 휴식 때문에 나뉠 수 있으며, 휴식이 없으면 각 작업을 한 구간으로 표시합니다. 이전에 저장한 일정과 완료 체크는 유지되며 ‘내 하루 일정 만들기’를 누르면 새 배치 방식이 적용됩니다.

할 일·고정 시간·설정·마지막 생성 일정·완료 체크·하루 기록·저장한 항목·보기 방식·타이머·알람 상태는 Windows 사용자 데이터 폴더의 `dayflow-state.json` 파일에 자동 저장됩니다(일반적으로 `%APPDATA%/Dayflow/` 또는 `%APPDATA%/dayflow/`). 목표 이름·비중·직접 시간 등을 수정하면 입력 즉시 날짜별 목표와 마지막 화면을 한 번에 저장합니다. 저장 버튼이나 일정 만들기를 다시 누를 필요가 없으며, 이미 생성된 일정도 유효한 수정값에 맞춰 즉시 반영됩니다. 앱을 종료했다 다시 실행하거나 배포 폴더를 옮겨도 같은 Windows 계정에서 복원됩니다. 중복 실행하면 기존 창을 보여주어 두 창이 서로의 저장값을 덮어쓰지 않게 합니다. 기존 로컬 저장소의 데이터는 처음 실행할 때 자동으로 옮깁니다. 한 번 일정을 만들면 비중·고정 시간·시작 시각·전체 시간·집중과 휴식 설정을 바꾸거나 항목을 추가·삭제·이동할 때 일정과 배분 바, 원형 보기가 즉시 다시 계산됩니다. 고정 시간이 늘어나면 남은 시간에서 다른 작업을 비중에 맞춰 재분배합니다. 완료 체크는 작업과 시작·종료 시각이 같은 구간만 유지하며, 변경된 구간은 미완료로 표시합니다. 입력 중 값이 비어 있거나 시간이 충돌하면 오류와 함께 마지막 유효한 일정을 유지하고 내보내기를 잠시 막습니다. 입력을 고치면 자동 반영됩니다. ‘일정 만들기’를 다시 누르면 완료 체크가 초기화됩니다. 네트워크 연결, 원격 저장, 자동 업데이트는 없습니다.

‘하루의 흐름’에서는 목록형과 원형 하루일과표를 선택할 수 있습니다. 원형은 위쪽 0시부터 시계 방향으로 24시간을 표시하며, 색칠하지 않은 영역은 일정 없는 시간입니다. 자정을 넘긴 구간도 해당 시각에 이어 표시하고 상세 시간에는 ‘다음 날’을 표기합니다. 구간을 클릭하거나 아래 선택창에서 고르면 작업명과 시간을 확인하고 완료 여부를 바꿀 수 있습니다. 완료 체크는 두 보기에서 공유하며 보기 방식은 로컬에 저장됩니다. 원형을 선택한 상태에서 PDF를 저장하면 원형과 전체 구간 목록을 함께 포함합니다.

## 목표와 달력 탭

상단 중앙의 ‘목표’ 탭에서 선택한 날짜의 작업·고정 시간·시간표를 편집하고, ‘달력’ 탭에서 날짜별 일정과 완료 기록을 확인합니다. 달력에서 날짜를 고르고 ‘목표·일정 편집’을 누르면 해당 날짜의 목표 화면이 열립니다. 목표 화면 위 날짜 입력으로도 다른 날로 이동할 수 있으며 ‘오늘’ 버튼으로 오늘 날짜에 돌아옵니다. 새 날짜의 작업 목록은 비어 있고 시간 설정은 직전 날짜의 값을 가져옵니다. 할 일이나 약속을 추가하고 ‘일정 만들기’를 누르면 선택한 날짜에 시간표가 생성됩니다. 날짜마다 입력·시간 설정·완료 체크를 별도로 저장하며 아직 시간표를 만들지 않은 목표도 달력에 표시합니다. 일정을 만들거나 수정하면 해당 날짜에 자동 저장되며, 완료 체크한 구간의 이름·시작과 종료 시각·배정 시간이 기록에 남습니다. 달력의 점은 일정이 저장된 날, 색의 진하기는 완료 체크한 집중 시간입니다. 월 이동 버튼이나 월 선택창으로 과거 기록을 보고 ‘오늘’로 돌아올 수 있습니다.

이미 완료한 구간은 같은 날 일정을 다시 배분하거나 새로 만들어도 기록에 남습니다. 현재 일정에서 해당 구간의 완료 체크를 취소하면 그 완료 기록도 취소됩니다. 앱을 열면 마지막으로 편집한 날짜를 복원합니다. 자정이 지나도 현재 편집 중인 날짜는 그대로 유지되므로 새 날짜를 선택하거나 ‘오늘’을 눌러 이동하세요. 일정 생성·수정·완료 체크는 화면에서 선택한 날짜에 저장됩니다. 완료 시간은 실제 스톱워치 측정이 아니라 체크한 구간의 배정 시간이며, 자정을 넘는 구간도 일정을 시작한 날짜의 기록에 포함합니다. 모든 기록은 이 컴퓨터에만 저장되고 외부로 전송되지 않습니다. 이 기능 추가 이전의 날짜별 기록은 복원할 수 없으며 기존 일정은 현재 날짜부터 기록합니다.

## 타이머와 스톱워치

상단 ‘일정 알람’에서 ‘일정 알람 시작’을 누르면 만든 일정의 첫 구간부터 목표 → 휴식 → 다음 목표가 자동으로 진행됩니다. 각 구간의 배정 시간만큼 카운트다운하며 끝나면 소리와 화면 안내, Windows 알림으로 다음 구간을 알려줍니다. 현재 구간은 일정표에서 강조되며 일시정지·계속하기·중지를 지원합니다. 알림 소리를 끄거나 ‘소리 테스트’로 확인할 수 있습니다. Windows 알림은 시스템 알림 설정에 따라 보이지 않을 수 있습니다.

알람은 시작 버튼을 누른 시점부터 진행하므로 원래 일정의 시각과 달라질 수 있습니다. 실행 중 일정 변경은 다음 알람 시작부터 적용하며, 실제 작업 완료 체크는 직접 합니다. 창을 최소화해도 진행되지만 앱을 종료하면 알림이 멈춥니다. 다시 실행하면 남은 시간을 일시정지 상태로 복원하며 ‘계속하기’로 이어갈 수 있습니다. 시작할 때 실행 중인 독립 타이머는 일시정지합니다.

상단에서 집중·휴식 모드를 고르고 1~180분을 설정한 뒤 ‘시작’을 누릅니다. ‘일시정지’와 ‘계속하기’로 남은 시간을 이어갈 수 있고, ‘초기화’로 설정한 시간으로 돌아갑니다. 모드를 바꾸면 일정 설정의 집중 기준 또는 휴식 시간을 가져옵니다. 일정에 휴식이 없으면 휴식 타이머는 기본 5분으로 시작합니다. 실행 중에는 모드와 시간을 바꿀 수 없습니다.

타이머는 일정과 독립적으로 작동하며 집중·휴식 시간이 끝나면 화면 안내와 함께 알림 소리를 재생합니다. 일정 알람의 ‘알림 소리’ 설정은 상단 타이머에도 함께 적용됩니다. 상태는 로컬에 저장됩니다. 실행 중 앱을 닫아도 실제 시간은 계속 흐르고, 다시 열면 마감 시간을 기준으로 남은 시간을 복원합니다. 앱을 닫은 동안에는 완료 알림이 표시되지 않습니다. PDF에는 타이머를 포함하지 않습니다.

‘스톱워치’ 모드는 00:00:00부터 경과 시간을 시:분:초로 측정합니다. 시작·일시정지·계속하기·초기화를 지원하며, 일시정지 중에는 시간이 증가하지 않습니다. 잠시 다른 모드로 전환했다가 돌아와도 스톱워치 측정값을 유지합니다. 실행 중에는 모드를 바꿀 수 없으므로 먼저 일시정지하세요. 스톱워치 상태도 로컬에 저장하며 실행 중 앱을 닫았다가 다시 열면 닫혀 있던 시간을 포함해 복원합니다.

## 구조

- `planner.js`: 날짜별 목표·일정 저장 및 기존 기록 복원
- `scheduler.js`: 비중 배분 및 휴식 슬롯 생성
- `renderer.js`, `index.html`, `style.css`: 화면과 로컬 저장
- `timer.js`: 실제 경과 시간 기준 타이머 및 상태 복원
- `main.cjs`, `preload.cjs`: 데스크톱 창과 파일 내보내기
- `tests/`: 시간 보존, 비율, 자정 넘김 및 잘못된 입력 검증

목록형과 원형 모두 시간 배분 바와 색상 범례를 표시합니다. 바 안에 할 일 이름을 표시하며, 마우스를 올리거나 키보드로 선택하면 전체 이름과 배정 시간을 확인할 수 있습니다.

캘린더 연동, 일정 구간의 드래그 시간 편집, 남은 하루 재배치 기능은 포함되지 않습니다.

## 식사·이동 등 고정 시간

‘할 일’ 박스에는 비중으로 배분할 작업을, 별도의 ‘고정 시간’ 박스에는 식사·이동·약속 등을 추가합니다. 고정 시간은 이름과 소요 시간(1~1439분)을 정해 여러 개 추가할 수 있습니다. 시작 시각은 선택 사항입니다. 지정하면 해당 시각을 우선하고, 비우면 목록 순서대로 한 구간으로 배치합니다. 각 박스에서 항목을 수정·삭제하거나 손잡이로 순서를 바꿀 수 있으며, 기존에 저장된 고정 항목도 고정 시간 박스에 표시됩니다. 두 목록을 합쳐 최대 30개까지 추가할 수 있습니다.

고정 시간을 먼저 확보한 뒤 남은 시간 안에서 비중에 따른 작업과 집중·휴식 시간을 계산합니다. 고정 활동은 집중·휴식 합계와 별도로 표시되며 목록형, 원형, 배분 바, PDF·CSV에 포함됩니다. 지정 시각이 겹치거나 전체 시간 밖에 있거나 소요 시간의 합이 전체 시간을 넘으면 안내합니다. 고정 활동을 연속 배치하기에 너무 작은 틈은 ‘빈 시간’으로 표시하며, 작업별 비중과 고정 활동의 길이를 보존합니다. 시작 시각을 지정한 항목은 목록 위치보다 시각이 우선하므로 진행 중인 작업을 중단하고 그 뒤에 이어갈 수 있습니다.

고정 항목 오른쪽 저장 아이콘을 누르면 ‘저장한 항목’에 보관됩니다. 펼친 뒤 항목을 선택하고 ＋를 누르면 이름·소요 시간·시작 시각을 다시 추가합니다. 같은 이름으로 저장하면 설정을 갱신합니다. 목록에서 삭제해도 저장 항목은 유지되며, 저장 항목 옆 ×로 별도 삭제합니다. 모든 저장은 이 컴퓨터 안에서 이루어집니다.
